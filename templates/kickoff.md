# Короткий шаблон задачи

Задача живёт в YouTrack; этот текст — её описание. Перед работой агент
использует [порядок работы](../ai/WORKFLOW.md) и
[ограничения](../ai/RESTRICTIONS.md). Постоянный контекст и правила в задание
не копируются.

```text
# Задача (ID YouTrack)
Что нужно сделать и какой пользовательский результат.

# Приёмка
Как понять, что готово: 1–3 сценария, которые проверят глазами на стенде.

# Границы
Что входит и что нельзя менять; продукты и репозитории.

# Риск
Обычный / деньги / права / миграция / данные.
```

Локальные проверки (тесты, lint, typecheck, build) агент запускает сам по
[политике проверок](../ai/RESTRICTIONS.md#проверки); отдельно их перечислять
не нужно. В задании указывают только то, что выходит за эту политику:
например, разрешённое действие на общей среде.

## Пример

```text
# Задача SUMMY-123
Пустое состояние в списке записей клиентского приложения.

# Приёмка
Клиент без записей видит короткий текст и кнопку «Записаться».

# Границы
Только client-app; API и backend не менять.

# Риск
Обычный.
```
