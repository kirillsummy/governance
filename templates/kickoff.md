# Короткий шаблон задачи

Перед работой агент использует [порядок работы](../ai/WORKFLOW.md) и
[ограничения](../ai/RESTRICTIONS.md). Постоянный контекст и правила в задание не
копируются.

```text
# Задача
Что нужно сделать.

# Требуемый результат
Как должен выглядеть готовый результат.

# Ограничения
Что в рамках этой задачи нельзя менять или делать.

# Проверки
Какие проверки оператор прямо разрешает выполнить.
Если раздел пуст — никакие проверки не запускать.
```

## Пример

```text
# Задача
Добавить пустое состояние в список записей клиентского приложения.

# Требуемый результат
При отсутствии записей показаны короткий текст и кнопка создания записи.

# Ограничения
Не менять API и backend.

# Проверки
Разрешено запустить существующий typecheck клиентского приложения.
```
