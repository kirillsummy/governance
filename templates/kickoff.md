# Шаблон поручения

Поручение содержит только переменную часть; постоянные правила — в
[уставе](../CHARTER.md) и [порядке работы](../ai/WORKFLOW.md) и в текст не
копируются. Работа живёт частью сводной карточки категории или общей задачей
([доска](../ai/WORKFLOW.md#доска-youtrack)).

```text
# Задача (ID YouTrack)
Проблема и требуемый результат.

# Готово, когда
1–3 проверяемых критерия.

# Ограничения
Только существенное и выходящее за постоянные правила: продукты, что
нельзя менять, отключённая выкладка на Dev, явный запрос проверок.
```

## Пример

```text
# SUM-124
Клиент без записей видит пустой список без пояснения.

# Готово, когда
Клиент без записей видит короткий текст и кнопку «Записаться».

# Ограничения
Только client-app; API и backend не менять.
```
