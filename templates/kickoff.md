# Короткий шаблон задачи

Работа живёт в YouTrack частью [сводной карточки категории](../CHARTER.md#доска-youtrack-сводные-карточки-категорий)
или общей задачей; этот текст — описание части. Перед работой агент
использует [порядок работы](../ai/WORKFLOW.md) и
[ограничения](../ai/RESTRICTIONS.md). Постоянный контекст и правила в задание
не копируются.

```text
# Сводная (ID YouTrack) · часть (исходный ID, если есть)
Что нужно сделать и какой пользовательский результат.

# Приёмка
Как понять, что готово: 1–3 сценария; их проверяют при подготовке
production-кандидата, а не при доставке на TEST.

# Границы
Что входит и что нельзя менять; продукты и репозитории.

# Риск
Обычный / деньги / права / миграция / данные.
```

Тесты, lint, typecheck и проверочные сборки во время разработки и доставки
на TEST не запускаются — только при подготовке production
([порядок](../CHARTER.md#разработка-и-доставка-на-test)); перечислять их в
задании не нужно. В задании указывают только то, что выходит за этот
порядок: например, особое ограничение на общей среде.

## Пример

```text
# Сводная SUM-123 · часть SUM-124
Пустое состояние в списке записей клиентского приложения.

# Приёмка
Клиент без записей видит короткий текст и кнопку «Записаться».

# Границы
Только client-app; API и backend не менять.

# Риск
Обычный.
```
