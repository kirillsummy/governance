# Шаблон памятки для `AGENTS.md` продукта

Вставь блок ниже в `AGENTS.md` продукта ближе к началу (`CLAUDE.md` продукта —
одна строка `@AGENTS.md`, второго свода правил не заводить).

**Зачем:** облачная сессия видит только свой репозиторий и до общего устава
не дотянется. Памятка — не копия устава, а минимум: кто есть кто, база и
защищённые ветки этого репозитория, как сдавать, указатель на канон.
Остальное в памятке — продуктовые грабли, которых нет в уставе.

**Правило:** памятка короткая и меняется редко; канон правится в одном
месте — `governance/CHARTER.md`. Роли, порядок сдачи и заморозку коммита в
памятке не пересказывать сверх блока: копия расходится с уставом молча.

---

```markdown
## Роли и процесс — канон экосистемы

> Устав — **[`governance/CHARTER.md`](https://github.com/kirillsummy/governance/blob/main/CHARTER.md)** (роли, ветки, хендофф, эстафета релиза), контракты стыков — [`governance/contracts/`](https://github.com/kirillsummy/governance/tree/main/contracts). Здесь — только то, что нужно сессии этого репозитория; при расхождении побеждает устав.

Кирилл — владелец: его слово обязательно для выкатки, денег, необратимого и вкусового. Команда — тройка: **Разработчик** строит (роль одна, сессии задачные), **Релиз-инженер** (постоянная сессия) принимает — ревью, мерж, теги, выкатка по фразе владельца, **Архитектор** готовит задания и держит стыки. **Ты — задачная сессия разработчика**: ветка от <базовая ветка из таблицы «Ветки» устава> (`feature/<фича>`), защищённые ветки — <перечень из той же таблицы>; сама НЕ мержишь, НЕ тегируешь, НЕ деплоишь; упёрся в чужой продукт — опиши развилку в PR, не решай за него.

**Сдача:** проверки зелёные → пуш своей ветки → PR с явной базой `--base` (умолчание GitHub укажет не туда) → `CHANGELOG` `[Unreleased]` → тело PR по [шаблону хендоффа](https://github.com/kirillsummy/governance/blob/main/templates/handoff.md) → письмо релиз-инженеру, последняя строка:

    Релиз-инженеру: проведи ревью и смержи <ветка> (commit <полный SHA>)

Не готово даже к мержу → `Релиз-инженеру: не мержить, ветка в работе`. Отданный коммит заморожен — правки по ревью новыми коммитами поверх, с новым SHA; выкатку разрешает только владелец.
```

Сторож канона (`scripts/check-canon.mjs`) проверяет в памятках финальную
строку с `(commit <полный SHA>)`, слова «новыми коммитами», базу и защищённые
ветки продукта и запрет пуша в защищённую ветку продукта.
