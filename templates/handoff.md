# Шаблон отчёта (хендофф)

Отчёт исполнителя о сдаче: короткий и честный по стадиям
([устав](../CHARTER.md#приёмка-и-отчёт)). Носитель — часть сводной или задача
YouTrack и ответ в чат поручения; полный текст не копируют в несколько мест.
Файл `HANDOFF-<дата>-<тема>.md` — только для адресатов вне GitHub.

```markdown
Задача: <ID YouTrack> · часть: <исходный ID или «новая»> · ответственный: <кто>

## Сделано
- <результат по критериям готовности>

## Опубликовано
- <репозиторий>: `test` @ <полный SHA>

## Развёрнуто
- Dev: <выпуск, результат команды, VERSION, ревизия БД> / выкладка на Dev отключена оператором
- Prod: не менялся / <документ выпуска>

## Проверки
- Тесты не проводились / проверены только миграции БД: <ревизия, сохранность данных, копия>

## Осталось
- <остатки и блокеры с адресатом; вопросы — номер в SUM-96/SUM-97>
```

Если было ревью Claude — одна строка: SHA и исход замечаний. При снятии
функционала — строка «по следам решения: снято …, осталось намеренно …».
