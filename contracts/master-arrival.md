# SUM-194 — мастер отмечает «Клиент пришёл»

Решение владельца 07.10.2026: отметка «Клиент пришёл» в приложении мастера
уходит в YClients как «Пришёл» (`attendance=1`).

## Как идёт отметка

- `POST /v1/master/appointments/{id}/arrived` сразу ставит записи `arrived` в
  SUMMY; ответ ручки YClients не ждёт.
- Для записи YClients в той же транзакции встаёт досылка в
  `master_arrival_deliveries` (миграция `0261`). Фоновый цикл API отправляет её
  сразу и повторяет раз в минуту до конца дня записи.
- Перед отправкой запись читается из YClients: уже «Пришёл» — второй раз не
  шлём; удалена или «Не пришёл» — досылка снимается. Отказ YClients по
  содержанию — `rejected`, конец дня без успеха — `expired`. SMS клиенту не
  уходит.
- Пока досылка в очереди, импорт записей не откатывает `arrived`; неявка и
  удаление в YClients побеждают.

## Выключатель и окружения

- `MASTER_YCLIENTS_ARRIVAL_ENABLED` включён по умолчанию, служит аварийным.
- Там, где YClients только читается, цикл не запускается. На локальном стенде
  YClients отключён заглушкой.
