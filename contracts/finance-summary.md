# Контракт: управленческая сводка (SUM-124, SUM-96 № 14)

Прямые ответы пользователя 04.10.2026: доступ — владелец, бухгалтер и
управляющий только по своим филиалам; сводку строить по имеющимся
подтверждённым данным с явной пометкой неучтённых расходов и налогов. Состав
обязательных показателей, формулы и утверждение денежных значений — открытый
№ 14. Пишет backend (`GET /v1/finance/summary`, `0eec9e70bbf50c4d3ab520de0ba7f5d9520ebb59`), читает CRM
(«Финансы», BFF `/api/finance/summary`).

## Доступ

- `owner`, `accountant` — вся организация; `manager` — только филиалы его
  действующих выдач (`granted_location_ids`): общий итог считается только по
  ним, фильтр по чужому филиалу — 403. Прочим ролям — 403. Организационная
  изоляция — по `organization_id` сессии.
- CRM: раздел `finance` с потолком ролей `owner`, `accountant`, `manager`
  ([crm-navigation](crm-navigation.md)).

## Показатели (только существующие определения)

Период — `date_from`…`date_to` (до 370 дней), даты визитов в часовом поясе
платформы; по филиалам и итог по доступным филиалам.

| Показатель | Определение |
|---|---|
| Визиты | состоявшиеся записи клиентов (`arrived`, `completed`) |
| Оказано услуг | сумма позиций (`final_amount`) состоявшихся записей |
| Оплаты, подтверждённые YClients | позиции записей с последним снимком `paid_full` — определение «Показателей KPI» ([analytics-kpi](analytics-kpi.md)); не бухгалтерская выручка |
| Визиты без подтверждения | состоявшиеся записи без `paid_full` — покрытие источника оплат |
| Начислено мастерам | `payroll_closing_days.payout_rub` по закрытиям записей филиала, без исключённых; бонусы и штрафы мастеров не включены; начисления без привязки к записи — отдельной строкой у организации |

Ответ несёт `definitions`, время расчёта и последнего успешного синка записей
YClients, список `missing`: выручка как правило признания, аренда и
коммунальные, налоги, прочие расходы, оплата администраторов (в табеле, не
сведена), управляющей и уборщицы, возвраты и бонусы клиентов. Неизвестное не
подменяется нулём; «доходы минус расходы» и прибыль не считаются, новых
ставок налогов и расходов нет.
