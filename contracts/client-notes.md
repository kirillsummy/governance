# Отзывы сотрудников о клиенте: общая история заметок

Прямое поручение владельца 07.10.2026: отзывы сотрудников о клиенте в CRM.
Backend владеет данными, авторством, доступом и аудитом. Код опубликован в
backend `test` `fc39b9bf` и CRM `test` `8d09aa79`, доставлен на Dev выпуском
[crm-visual-dev-20261007](../docs/releases/dev-crm-visual-fixes-2026-10-07.md).
Пользовательский сценарий не проверялся.

## Данные и история

Одна существующая `client_notes` для CRM и кабинета мастера. Запись содержит
связь с клиентом, тело, источник, стабильную ссылку автора, дату источника и
время создания. История append-only: исправление — новая запись, чужие и
прежние записи не перезаписываются. Живые внутренние заметки показываются
новыми сверху по дате источника, а при её отсутствии — по дате создания.

Автор определяется проверенной сессией, не выбирается в форме. Мастерская
ссылка `staff:<UUID>` сохранена; новая CRM ссылка `crm:<user_id>`.
Имя разрешается только по такой точной ссылке. Неизвестный автор импорта
остаётся неизвестным; похожее имя не устанавливает авторство.
Исходные даты и текст импортов сохраняются, время получения не подменяет
дату заметки. Новая внутренняя запись имеет `source=summy`.

Текст очищается по краям, непустой, не больше 4000 символов. Повтор полного
текста того же автора для того же клиента возвращает прежнюю запись;
нового дубля и нового аудита нет. Каждое новое добавление и его автор
фиксируются в `clients_audit` в той же транзакции.

## CRM API и граница

- `GET /v1/clients/{client_id}/notes` → `{items:[{id,body,source,author_name,noted_at,created_at,source_created_at}]}`.
- `POST` по тому же пути, строго `{body}` → одна запись, HTTP 201. Ни автора,
  ни дату, ни источник передать нельзя. Новых edit/delete ручек нет.
- Нужны сервисный токен, живая CRM-сессия, открытый раздел «Клиенты» и роль
  владельца или управляющего. Клиент принадлежит своей организации;
  управляющему доступен только клиент с визитом в его выданных филиалах,
  по существующей границе API предпочтений.
- `author_name` и `source_created_at` могут быть `null`; `noted_at` равен
  дате источника либо `created_at`. Отсутствие автора или даты источника
  нельзя скрыть выдуманными значениями.

## Прежний кабинет мастера

Чтение и добавление через собственную запись/обслуженного клиента работают
по прежним проверкам. Новая CRM заметка участвует в существующей внутренней
ленте с разрешённым именем её автора. Это изменение не открывает мастеру
чужих клиентов или визиты и не снимает оставшиеся вопросы о видимости
заметок всех авторов из [master-client-visibility](master-client-visibility.md).

Миграций нет; импортные строки не меняются. Проверенные пользовательские
сценарии и доставка фиксируются отдельно в CHANGELOG/текущем состоянии.
