# Запуск и управление 11 потоками

Команда состоит из одного менеджера и десяти исполнителей. Она запускается
только для конкретного поручения владельца. Наличие навыка её не запускает.

## Интерактивный Claude Code на Windows

Установлен официальный Claude Code, выполнен собственный вход владельца.
В PowerShell из каталога репозиториев задайте пути **своей** машины:

```powershell
$repoRoot = (Get-Location).Path
$governanceDir = Join-Path $repoRoot 'governance'
$previousTeams = $env:CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS
try {
    $env:CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS = '1'
    claude --model opus --effort high --strict-mcp-config --permission-mode auto --teammate-mode in-process --add-dir $governanceDir
} finally {
    if ($null -eq $previousTeams) {
        Remove-Item Env:CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS -ErrorAction SilentlyContinue
    } else {
        $env:CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS = $previousTeams
    }
}
```

Обычная команда `claude` должна указывать на официальный установленный CLI.
`--add-dir` загружает `.claude/skills` Governance; простое разрешение доступа
к каталогу в settings не загружает навыки. Если checkout Governance содержит
чужие изменения, используйте отдельный чистый checkout актуального `main`.

В открывшемся Claude введите:

```text
/summy-claude-team-11 <конкретный список задач>
```

Менеджеру можно написать:

```text
Ты менеджер. Создай Agent Team: ты и 10 исполнителей на Opus/high.
Распредели перечисленные мной задачи; сначала сверяй уже работающие сеансы.
Дай каждому отдельный рабочий каталог и владение файлами.
Веди очередь и собирай точные коммиты. Расскажи, кто реально запущен,
кто ждёт зависимости и что осталось. Публикация и выкладка только
в пределах моего поручения; новых задач и расписаний не создавать.
```

Пишите менеджеру «статус всех», «перераспредели задачу…», «уточнение для…».
В панели агентов интерактивного CLI выберите исполнителя стрелками, нажмите
Enter для просмотра его диалога и прямого сообщения. Управление этой панелью
может отличаться в более старой версии CLI.

Не обещается восстановление всей команды одним `/resume`: перед выходом
менеджер сохраняет реестр и коммиты. Не запускайте 11 экземпляров одной sessionId.

## Что показывает окно 127.0.0.1:8770

Окно перечисляет зарегистрированные самостоятельные запуски и позволяет
отправить уточнение **выбранной sessionId**. Enter отправляет, Shift+Enter
добавляет строку. Статус доставки отличает очередь, квитанцию CLI и ответ.
Старый запуск `-p <prompt>` получает уточнение после завершения через продолжение
той же сессии; stream-json managed runner принимает текст во время работы.

Встроенная команда интерактивного менеджера живёт в CLI. Её десять teammates
не объявляются автоматически десятью управляемыми потоками окна. Окно не
создаёт native Agent Teams: все его продолжения запускаются с `-p`, а
официальная документация исключает создание teammates в таком режиме.

Поэтому для **одного менеджера внутри Claude** используйте интерактивный
вариант выше. Для **11 самостоятельных строк в окне** требуется отдельная
регистрация/запуск каждого managed-сеанса и механизм координации; этот навык
не утверждает, что такая команда уже создана или интегрирована с Agent Teams.

Экспериментальные команды используют общий лимит аккаунта. Одиннадцать
потоков — организация работы, а не гарантия скорости или доступной квоты.
