# Поддержание Governance

Правила документирования — [устав](../../../CHARTER.md#документация). Выбери
единственное каноническое место по [входу](../../../AGENTS.md): правило —
устав, процедура — [порядок работы](../../WORKFLOW.md), общее поведение —
контракт, справка — `docs/`, факт изменения — `CHANGELOG.md`, подтверждённое
состояние — `docs/current-state.md`. Второй полный пересказ не создавай;
ссылайся.

Для утверждения сохрани источник, SHA и уровень доказательства: код ветки,
развёрнутый артефакт, наблюдение среды или план. Старый замер не превращай
в живой статус. Устаревшее убери из действующих разделов или перенеси в
[историю](../../../docs/history/README.md) с пометкой; исторические отчёты не
переписывай. При переносе файла исправь относительные ссылки и якоря во всех
действующих документах.

Ход задачи не копируй: он в YouTrack. Проверки документации
(`scripts/check-docs.mjs`, `scripts/check-canon.mjs`) запускаются по
[политике проверок](../../../CHARTER.md#проверки-и-ci).
