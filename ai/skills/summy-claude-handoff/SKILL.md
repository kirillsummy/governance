# Координация Claude Code

Роли Codex и Claude, приёмка и отчёт — в [уставе](../../../CHARTER.md#роли-и-ответственность),
процедура — в [порядке работы](../../WORKFLOW.md#координация-codex-и-claude).
Здесь — способ запуска и наблюдения, переносимый на любой ПК.

## Передача

1. Сверь задачу YouTrack, Git-состояние затронутых репозиториев и уже
   работающий сеанс Claude; чужую работу сохрани.
2. Поручение — UTF-8 файл по [шаблону](../../../templates/kickoff.md): задача,
   результат, критерии готовности, существенные ограничения. Без предыстории,
   объяснения ролей и пересказа постоянных правил. Имя владельца поручения в
   поручениях, статусах и сообщениях не упоминай.
3. Запускай официальный Claude Code CLI из каталога репозиториев SUMMY без
   MCP-серверов (`--strict-mcp-config`), с моделью, выбранной для SUMMY, и
   потоковым журналом: `-p --permission-mode auto --output-format stream-json
   --verbose`, stdout — в `.tmp/<задача>.jsonl` каталога чатов, stderr —
   отдельно. Токены, cookies и файлы сессий не извлекай и не передавай.
4. Запиши в `.tmp/claude-status.json` поля `task`, `phase`, `summary`,
   `updatedAt`, `milestones`, `claudeWorking`, `awaitingReply` и абсолютные
   пути `runLog`, `promptFile` под `.tmp`. Claude обновляет статус на
   контрольных точках: код, публикация, выкладка, блокер, завершение.

## Наблюдение

Локальное окно диалога — `node ai/skills/summy-claude-handoff/scripts/dialog.cjs
<каталог-чатов-SUMMY>` на `127.0.0.1:8770`. Оно читает только выбранные
`runLog` и `promptFile` и показывает поручение, состояние («Работает», «Ждёт
ответ», «Ждёт указаний», «Не подключен») и ответы Claude с безопасным
оформлением Markdown, без служебных событий и внутренних рассуждений. Окно
только показывает: других сессий оно не запускает ни автоматически, ни
кнопкой. Панель статуса `scripts/claude-status-server.cjs` на
`127.0.0.1:8769` — дополнительная, не вместо диалога. Серверы не публикуются
в сеть и не хранят секретов.

Между контрольными точками за каждой командой не следят. Результат
возвращается исходному чату Codex: он читает отчёт Claude, журнал CLI-сеанса
и сверяет факты — поручение, опубликованные SHA, результат развёртывания,
YouTrack и Governance. Отчёт Claude сам по себе выкладку не доказывает.

## Остановка и возобновление

При остановке прерви только порученный процесс Claude, проверь его
завершение и зафиксируй подтверждённый этап. При возобновлении сверь Git,
YouTrack и среду; внешние записи вслепую не повторяй.

Локальные копии этого окна и инструкций на рабочем ПК содержат только ссылки
на канон и особенности машины; пути и учётки ПК в Governance не публикуются.
