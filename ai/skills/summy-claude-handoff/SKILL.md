# Координация Claude Code

Применяй навык, когда владелец поручает работу Claude или спрашивает о переданной задаче. Прочитай [устав](../../../CHARTER.md), [порядок работы](../../WORKFLOW.md) и инструкции затронутых репозиториев. Настройка рабочего ПК владельца сохранена в [LOCAL-WINDOWS.md](LOCAL-WINDOWS.md), а инструкции корневого `CLAUDE.md` — в [LOCAL-CLAUDE.md](LOCAL-CLAUDE.md). Их рабочие копии лежат соответственно в `skills/claude-summy/SKILL.md` каталога чатов и `CLAUDE.md` локального каталога репозиториев SUMMY. Проверь наличие файлов и средств запуска, не считай эти пути переносимыми на другой хост.

В новых промтах, поручениях, статусах и сообщениях Claude не упоминай имя владельца поручения. Исторические журналы не переписывай.

Перед новой передачей сверь задачу YouTrack, Git-состояние и уже работающий сеанс Claude. Сохрани чужую работу. Поручение пиши сухо и кратко: задача, затронутые части проекта, изменения, критерии готовности и только особые ограничения. Не добавляй предысторию, объяснение ролей и фразы «владелец указал», «по поручению владельца», «я разрешаю». Постоянные правила из `CLAUDE.md` и Governance не пересказывай; упоминай их только при конкретном конфликте или исключении. Отдельный сеанс Claude Code не является открытым окном Claude Desktop.

Перед запуском Claude открой владельцу локальное окно диалога. Его исходники сохранены в [scripts/dialog.cjs](scripts/dialog.cjs) и [scripts/dialog-client.js](scripts/dialog-client.js). Запуск из этого репозитория: `node ai/skills/summy-claude-handoff/scripts/dialog.cjs <каталог-чатов-SUMMY>`; на рабочем ПК владельца копия — `tools/claude-status/dialog.cjs` в каталоге чатов SUMMY, адрес `127.0.0.1:8770`. Окно читает только выбранные `runLog` и `promptFile` из `.tmp/claude-status.json` и показывает текст поручения и ответы Claude с безопасным оформлением Markdown, без служебных событий, вызовов инструментов и внутренних рассуждений. Дополнительная панель статуса [scripts/claude-status-server.cjs](scripts/claude-status-server.cjs) работает на `127.0.0.1:8769`; не открывай её вместо диалога. Статус обновляй при контрольных точках, без непрерывного мониторинга Git/YouTrack. Не публикуй локальный сервер в сеть и не переноси в него секреты.

Поручи Claude обновлять краткий статус после кода, публикации, выкладки, блокера и завершения. Между контрольными точками не следи за каждой командой. Всю разработку и изменение задач YouTrack выполняет Claude. Готовые изменения он публикует в `test` и разворачивает на TEST без отдельного одобрения; production требует отдельного разрешения. Тесты, smoke и ручные сценарии не выполняются без прямого запроса, сборка для доставки допустима. Ревью при необходимости одно, силами Claude; второго ревью Codex нет. После отчёта сверь требования, опубликованные SHA и результат команды развёртывания. Git и TEST отражай отдельно; отчёт Claude сам по себе не доказывает выкладку.

При просьбе остановить работу прерви именно порученный сеанс Claude, проверь завершение процесса и сохрани подтверждённый этап. При возобновлении заново сверь живое состояние и не повторяй внешние записи вслепую. Публикация, миграция и выкладка требуют своих полномочий и условий; разделяй локальный код, Git, TEST и production в итоговом статусе.

После завершённого ответа Claude локальный сервер автоматически запускает отдельный сеанс Codex CLI и передаёт ему пути к текущему статусу и журналу. Участие владельца не требуется. Кнопка «Позвать Codex» остаётся ручным запасным запуском и показывает состояние сеанса; диагностические журналы хранятся локально в `.tmp/codex-summon-*`. Это отдельный сеанс, не продолжение открытого чата Codex. Он не получает дополнительных полномочий на Git, миграции и выкладку: до этих действий действуют обычные проверки и решения Governance. Локальный сервер принимает ручной запрос запуска только со своего адреса и сам формирует поручение.
