# Комплект локального окна Claude

Исходники окна находятся в `../scripts/` относительно этого документа:
`dialog.cjs`, сервер/шлюз/реестр/managed runner, браузерный клиент и панель
лимитов. Основное окно не требует npm-зависимостей. Требуются Node.js и
официальный Claude Code с собственным входом. Поручения/логи остаются локально.

## Запуск

Из каталога Governance скопируйте `dialog-config.example.json` в игнорируемый
`dialog-config.json` рядом с `dialog.cjs`. Задайте абсолютные пути `claude`
(официальный CLI) и `cwd` (каталог репозиториев), `port` — 8770.
Файл с путями своей машины в Git не добавляйте.

```powershell
$dialogRoot = 'C:/local/summy-dialog'
node ai/skills/summy-claude-handoff/scripts/dialog.cjs $dialogRoot
```

`$dialogRoot` — входной каталог, где `.tmp` содержит поручения и журналы;
замените пример своим путём. Откройте `http://127.0.0.1:8770/`.
Сервис слушает loopback; не публикуйте его в интернет. Корень задавайте
явно; при отсутствии аргумента канонический комплект использует текущий каталог.
Сохранён параметр `--config <файл>` для конфигурации в другом локальном месте.

Новые запуски оформляйте через `claude-managed-runner.cjs` с `--root`, `--run`,
ровно одним `--session-id`/`--resume`, `--claude`, `--cwd`, `--prompt-file`
(UTF-8 файл под `.tmp`) и понятным `--task`. Существующую занятую сессию
не возобновляйте конкурентно. Рабочий контракт — основной SKILL.md.

## Список потоков

Кнопка «Info» на месте времени обновления открывает карточку выбранного потока:
состояние, примечание, этап, имя и тип запуска, время начала/завершения,
время статуса и обновления окна. Поля представлены отдельными строками,
отсутствующие данные не подменяются значениями. Длинная служебная строка
под переключателем убрана. Info закрывается при уходе мыши, повторном
нажатии, клике снаружи, Escape или уходе фокуса. Ошибка связи подсвечивает
кнопку даже при закрытой карточке; подробность находится внутри.

Все три кнопки верхней панели имеют единый стиль. «Перейти в сессию» открывает
компактное выпадающее окно: инструкция и команда, значок копирования справа
сверху. Команда только копируется, окно не запускает её автоматически.
Для работающего потока сохраняется предупреждение о параллельном запуске.

В панели уточнения поле фиксированной высоты находится слева, квадратная
кнопка «Отправить уточнение» — справа. Видимый заголовок поля скрыт,
доступное имя сохранено. Изменение размера отключено, при переполнении
показываются две серые кнопки прокрутки вверх/вниз вместо полосы.
Подсказки клавиш и режима доставки под полем скрыты; ошибки и результат
отправки отображаются. Enter отправляет, Shift+Enter добавляет новую строку.

Потоки сгруппированы по фактическому состоянию запуска: «В работе»,
«Ждут ответа», «Завершённые запуски», «С ошибкой», «Прерванные»,
«Состояние не проверено», «Не подключены». Заголовок группы показывает
количество потоков и не выбирается; пустые группы скрыты. В строках остаются
только названия. Порядок внутри группы сохраняется из реестра. Смена статуса
переносит поток между группами, сохраняя выбранный разговор. Завершённый запуск
не доказывает выполнение задачи, публикацию кода или выкладку.

## Лимиты

Кнопка «Лимиты Claude» открывает плавающее окно поверх переписки. В скрытом
состоянии браузер не запрашивает лимиты и не запускает их обновление. Открытие
или кнопка «Обновить» запрашивает свежий замер; ожидание результата опрашивается
только пока окно открыто. Уход мыши из кнопки и окна, клик снаружи или Escape
закрывает окно и прекращает браузерные запросы. На сенсорном экране работают
повторное нажатие и клик снаружи. Уже запущенный официальный замер может
завершиться на сервере после закрытия окна.

Панель читает только официальные `rate_limit_event` и минимальный снимок
официального statusLine. Отсутствие снимка означает отсутствие измерения.
OAuth/cookies, приватные credentials и внутренние файлы аккаунта не читаются.

Кнопка обновления использует отдельный ограниченный Windows PTY-помощник,
который запускает только официальный CLI с `--tools ""`, вызывает `/usage`
и завершает свой процесс. Публикация комплекта не запускает этот помощник.
Для него отдельно установите `@lydell/node-pty@1.2.0-beta.15` в
`$dialogRoot/.tmp/claude-usage-runtime` и подготовьте
`$dialogRoot/.tmp/claude-usage-probe.settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "node \"<absolute-scripts-path>/usage-statusline.cjs\" \"<dialog-root>\" \"claude-usage-probe-limits.json\""
  }
}
```

Замените пути на локальные, используйте `/` в путях Windows. Значения
`claude`/`cwd` берутся из локального config; пути с управляющими символами
cmd не допускаются. Без зависимости/настроек обновление показывает ошибку,
остальная работа окна продолжается. На других ОС PTY-обновление этой версии
не реализовано; чтение снимков и базовое окно независимы от него.
