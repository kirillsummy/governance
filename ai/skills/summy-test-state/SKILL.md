# Состояние Dev и БД

Начни с [инфраструктуры](../../../docs/infrastructure.md#подключение-к-dev-и-бд)
и [модели БД](../../../docs/database.md). Полный SHA `origin/test` и
работающий VERSION/образ на Dev сверяй раздельно: ветка не доказывает
выкладку, health не доказывает сценарий.

Снимок без изменений: `SUMMY_TEST_SSH_KEY=<ключ> SUMMY_TEST_KNOWN_HOSTS=<known_hosts>
python scripts/test_state.py` — VERSION всех продуктов, ревизия БД, образы,
состояние контейнеров, последний выпуск и замок. Используй только
подтверждённый доступ своей машины, строгую проверку SSH host key и свою
роль БД; ключи не копируй.

SQL-запись, миграция и restore этим навыком не выполняются. Клиентские
строки, пароли, дампы и значения `.env` в чат и Governance не выводятся.
Отчёт: время снимка, продукт, Git SHA, фактический VERSION/образ, ревизия БД
и граница проверенного. Состояние Prod из доступа к Dev не выводится.
