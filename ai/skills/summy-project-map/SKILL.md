# Карта задачи SUMMY

Начни с [состояния](../../../docs/current-state.md) и нужного раздела
[архитектуры](../../../docs/architecture/README.md). Укажи продукт-владелец и
читателей; BFF не считать отдельным владельцем бизнес-логики.

Сверь SHA и ветку: состояние `test` не переносить на production-ветку и Prod.
Используй [реестр источников](../../../docs/sources.md), затем читай только
относящийся к задаче router/DTO/service, BFF allowlist и вызывающий UI.
Для данных проверь Alembic head, для денег — существующие payroll/earnings.

Результат: краткая цепочка «пользователь → UI → BFF/API → домен → данные/внешний
сервис», затрагиваемые репозитории, контракт и нерешённые вопросы с источниками.
Карту не выдавай за завершённую реализацию.
