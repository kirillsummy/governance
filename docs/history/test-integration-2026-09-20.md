## Что перенесено и как разрешены пересечения

- **Backend:** надёжность БД/доставки заявок (`f53795b`), обращения мастера и
  месячные часы, клиентский API, общие заказы и sandbox-платежи (`ea174dd`),
  описание стенда (`f2117b3`), поддержка действующих сессий SUMMY ID у мастера
  (`3aee2d9`). Сохранена текущая реализация идентификации, приглашений и отзыва
  сессий; legacy master ID не обходит включённый SUMMY ID. Фоновые задачи обеих
  линий объединены с общей остановкой ресурсов.
- **Миграции backend:** добавлена только объединяющая ревизия
  `0121_merge_orders_identity`: родители `0120_quality_before_payment` и
  `0117_staff_invitations`. Старые миграции не переписывались, БД не обновлялась.
  `uv.lock` согласован с уже объявленным `PyJWT[crypto]`; добавились PyJWT и
  cryptography, остальные зафиксированные версии сохранены.
- **CRM:** календарь и карточки общих заказов (`d848696`), gateway-вход и
  приглашения SUMMY ID (`920a102`). Режим заказов использует общую серверную
  cookie `adminapp_gateway_session` и защищённый gateway-вход. После смены
  версии пользователю прежнего тестового режима может потребоваться новый вход.
- **Мастер:** общие заказы, статусы оплаты, обращения по сменам, причины снятия
  и текстовые замечания при приёме места (`01ce8b3`) объединены с текущим SUMMY ID.
- **Сайт:** группировка портфолио (`7309d23`), общая строка прайса (`d4bbd4a`),
  страница экосистемы (`541bb86`), инструмент проверки страниц (`8afdd9b`,
  не запускался), страница преподавателей (`9cad39c`). Сохранены текущая
  фильтрация вакансий и исправления доступности/позиционирования.
- **Клиент:** ранее восстановленная самостоятельная реализация из `work`
  теперь включена в `test` репозитория `client-app`. Источник приложения не
  переносился обратно в website. Схема входа по `/client/` требует отдельной
  настройки/выката стенда; Git-слияние само по себе URL не включает.

## Границы проверки и дальнейшая работа

По запрету владельца **автотесты, сборки, линтеры, миграции и deployment не
запускались**. Проверены только Git-граф, адреса репозиториев, SHA удалённых
веток, чистота рабочих копий и точечные конфликты исходников. Коммиты публикации
помечены `[skip ci]`, Git hooks при коммитах/пушах отключены; настройки CI не
переписывались. Обновление lock-файла — разрешение зависимостей без установки
приложения и выполнения его кода.

Работа объединённой версии на сервере, реальные SMS, YClients, платежи, чеки и
привязка карты этим слиянием не подтверждены. Эти пункты требуют отдельной задачи
с разрешением на соответствующие проверки и тестовый deployment.
