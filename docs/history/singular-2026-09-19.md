# Объединение исключительных веток в `singular` · 19.09.2026

Решение владельца: в каждом продуктовом репозитории остаётся не больше четырёх
веток — фактическая production-ветка, `test`, `work` и `singular`. Для backend
production остаётся `dev`; для master-app — default-ветка `feature/react-client`.

## Способ сохранения

`singular` создана от текущей безопасной базы (`work`, а в client-app — `main`).
Исключительные вершины включены архивным merge со стратегией `ours`: дерево
`singular` совпадает с базой, а все исходные SHA являются её предками. Такой merge
сохраняет Git-историю после удаления указателей, но не утверждает, что конфликтующий
код уже интегрирован. Для возврата отдельного изменения его анализируют и переносят
точечно; общий merge `singular` обратно запрещён без отдельного решения.

Перед удалением для каждой исходной ветки подтверждены:

1. точное совпадение локального `singular` с опубликованным `origin/singular`;
2. успешный `merge-base --is-ancestor <исходная ветка> origin/singular`;
3. неизменность дерева относительно выбранной базы.
