# Ветки и основная документация

## Governance

По решению владельца в этой задаче у удалённого `kirillsummy/governance` остаётся
**одна постоянная ветка — `main`**. В неё сведены DOC из PR #63, #64, #65,
контракт PR #62 и черновик уровней ИИ. Временную ветку подготовки удаляют после
успешного включения её коммитов в main. Удаление указателя не удаляет историю:
все исходные SHA остаются предками объединённого коммита.

Это правило относится к Governance. Ветки продуктов не удаляются и не мержатся
из-за изменения DOC. Участник не удаляет чужие локальные worktree ради чистоты GitHub.

## Остальные репозитории

Подтверждённые базовые ветки снимка 19.09: backend — `dev`; master-app —
`feature/react-client`; CRM, website, client-app, docs, context, workspace — `main`.
Изменение основной ветки или deployment отдельного продукта требует его процесса.

[Подробный исторический реестр 111 веток](history/branches-2026-09-19.md) содержит
SHA, сравнения с default и открытые PR **на момент сбора**, до нынешнего объединения.
Он сохранён для разбора истории, а не как обещание текущего числа веток на GitHub.
[Журнал объединения](history/consolidation-2026-09-19.md) связывает прежние документы
с единственной актуальной структурой.
