## Метод и границы

Все **111 удалённых веток девяти известных репозиториев** получены GitHub API
с пагинацией. Для каждой выполнен compare с закреплённым SHA default-ветки.
`+A / −B` — число коммитов только в ветке / только в базе. Это различие истории,
не оценка готовности, размера риска или статуса деплоя. «Файлы diff» — сравнение
GitHub от merge base до вершины; API возвращает максимум 300 файлов и до 250
коммитов в этом запросе. При лимите список нельзя считать полным. Ссылки compare
используют SHA, а не движущиеся имена веток.

Назначение взято из открытого PR; при его отсутствии приводится только предмет
последнего собственного коммита с явной оговоркой. Совпадение/отставание от базы
не доказывает, что ветку можно удалять. Текущий checkout, запущенный сервис и
работа другой сессии по GitHub metadata не устанавливаются. Открытый PR подтверждает
предъявленную работу, но не активную работу автора прямо сейчас.

Новая ветка этого DOC `feature/governance-doc-20260919` создана после сбора
исходного списка, основана на Governance SHA из таблицы репозиториев и используется
этой задачей. Она не входит в число 111 и не выдается за существовавшую до аудита.
